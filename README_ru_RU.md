# PDF Splitter - разделение PDF по пустым страницам

Скрипт для автоматического разделения PDF-документов по пустым страницам. Полезен для обработки сканированных документов.

## Возможности

- Автоматическое разделение PDF при обнаружении пустых страниц
- Полная совместимость синтаксиса с PdfSplitterX
- Встроенная утилита `scan_unix.sh` для сканирования документов
- Поддержка шаблонов имен для выходных файлов
- Работа с документами, отсканированными отдельно четные/нечетные страницы
- Отображение прогресса выполнения

## Использование

### Базовое разделение:
```bash
./PDFSplitterB.sh входной.pdf папка_выхода --t "шаблон"
Сканирование и разделение (через scan_unix.sh):
bash
./scan_unix.sh
Синтаксис шаблонов (аналогичен PdfSplitterX):
[Name] - оригинальное имя файла

[part] - номер части

<DATE>, <TIME> - дата и время

str# - порядковый номер

Поддерживаются все стандартные шаблоны PdfSplitterX

## Особенности
scan_unix.sh предоставляет:

Пошаговое сканирование листов (лицевая и обратная стороны)

Автоматическую сборку документа

Последующее разделение по пустым страницам

Полная совместимость с:

Шаблонами имен PdfSplitterX

Параметрами командной строки PdfSplitterX

Логикой обработки документов
