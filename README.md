# PDF Splitter - разделение PDF по пустым страницам
![Linux](https://img.shields.io/badge/Supports-Linux-000000?style=flat&logo=linux&logoColor=white)
![Windows](https://img.shields.io/badge/Supports-Windows-0078D6?style=flat&logo=windows11&logoColor=white)



Скрипт позволяет разделять отсканированные документы по отдельным файлам, а также 
может работать напрямую со сканером - упрощая сканирование большого количества документов 

![scanning][]

### Принцип работы
1. Вложить пустые листы между документами
2. Положить полученную стопку документов в сканер
3. Запустить программу PDF Spliiter
4. Указать папку в которую следует сохранить раздельные .pdf документы
5. Начать сканирование или указать исходный .pdf файл
6. [Опционально] При использовании сканера без автопереворта страниц - перевернуть стопку в сканере
7. PROFIT
